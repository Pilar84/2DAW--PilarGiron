# Este repositorio servirá para estructurar las siguientes carpetas con cada uno de los modulos e ir añadiendo las diferentes actividades que vayamos realizando.

## 📂 Organización por asignaturas

- **Inglés Profesional**: Ejercicios de comprensión y expresión en inglés técnico.  
- **IPE**: Actividades relacionadas con formación profesional y empresas.
- **Desarrollo Web en Entorno Cliente**: Prácticas de HTML, CSS y JavaScript.  
- **Desarrollo Web en Entorno Servidor**: Prácticas con Django, Python y bases de datos.  
- **Diseño Web de Interfaces**: Ejercicios de UX/UI y diseño de interfaces web.  
- **Proyecto Intermodular**: Proyecto integrador que combina varias asignaturas.  
- **Optativa**: Actividades de la asignatura optativa elegida (Git y GitHub)
- **Despliegue de Aplicaciones**: Ejercicios sobre despliegue, hosting y GitHub Pages.

> Este repositorio servirá como carpeta digital de todo el trabajo realizado durante el curso.
